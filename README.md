# Overview & Structure
## The dataset consists of measurements taken from 150 individual Iris flowers belonging to three related species. The data is perfectly balanced, meaning there are exactly 50 samples for each species.
### Total Rows: 150
#### Total Columns: 5 (4 numerical independent features + 1 categorical target variable)
##### Missing Values: None (It is a clean, complete dataset)
###### Features (The Columns)The data quantifies the morphologic variation of Iris flowers of three related species based on four physical measurements (expressed in centimeters):Independent Features (Predictors)sepal_length: The length of the outer, green structural leaf-like part of the flower ($cm$).sepal_width: The width of the sepal ($cm$).petal_length: The length of the inner, colorful petal leaf ($cm$).petal_width: The width of the petal ($cm$).
####### Dependent Variable (Target)
######## species: The specific class/label of the flower. It contains three categories:
-Iris-setosa
-Iris-versicolor
-Iris-virginica
